# Pre-Build Checklist — Before Creating the EXE

> Run this checklist before every `npm run tauri build` to ensure a clean, secure, and
> professional release.

---

## Phase 1: Verification Gates

- [ ] Run `npm run check` — TypeScript type check + all Vitest tests pass
- [ ] Run `npm run lint` — ESLint reports zero errors
- [ ] Run `cargo test` — Rust tests pass
- [ ] Run `npm run build` — Vite production build succeeds (frontend compiles)
- [ ] Verify no TypeScript `@ts-ignore` or `@ts-expect-error` comments remain in `src/`

---

## Phase 2: Version & Metadata✅✅✅

- [ ] **Version** — `src-tauri/tauri.conf.json` version matches intended release (currently `0.1.0`)
- [ ] **Identifier** — `com.codeeditor.app` ✓ keep as-is
- [ ] **Product name** — `"Code Editor"` ✓ keep as-is
- [ ] **Copyright** — already set in `tauri.conf.json`:
  ```json
  "bundle": {
    "copyright": "Copyright (c) 2026 Bhavin. All rights reserved."
  }
  ```

---

## Phase 3: Security✅✅✅

### CSP — CRITICAL
Current state: `"csp": null` (no protection). Already set to a secure baseline in `tauri.conf.json`:

```json
"app": {
  "security": {
    "csp": "default-src 'self'; script-src 'self' 'unsafe-eval' 'unsafe-inline' blob:; style-src 'self' 'unsafe-inline'; connect-src 'self' https://api.github.com; img-src 'self' data: asset:; font-src 'self' data:; worker-src 'self' blob:; frame-src 'self'"
  }
}
```

| Directive | Reason |
|-----------|--------|
| `'unsafe-eval'` | Monaco Editor requires `eval()` / `new Function()` for language services |
| `'unsafe-inline'` | React + Tailwind + shadcn inject inline styles |
| `blob:` (script-src) | Monaco workers are spawned as blob URLs |
| `https://api.github.com` | GitHub API calls (issues, PRs, CI status) |
| `asset:` (img-src) | Tauri's `asset:` protocol for bundled static resources |
| `data:` (img-src, font-src) | Inline images and icon fonts |
| `worker-src 'self' blob:` | Dedicated web workers from app + Monaco workers |

- [ ] CSP already applied — verify in `tauri.conf.json`
- [ ] Test all features (editor, terminal, git, GitHub panel) work with CSP active

### Permissions Audit
- [ ] Review `src-tauri/capabilities/default.json` — remove any `fs:scope-*` permissions the app doesn't use
- [ ] Confirm `shell:allow-open` is scoped to safe protocols only (prevents arbitrary command injection)

---

## Phase 4: Icon Quality✅✅✅

- [ ] `icons/icon.ico` is a multi-resolution ICO (16×16, 32×32, 48×48, 256×256)
- [ ] Icons are NOT the placeholder generated by `scripts/generate-icons.mjs`
- [ ] Icons look good at both 100% and 200% DPI scaling
- [ ] Verify icon shows correctly in: Windows Explorer, taskbar, alt+tab switcher

**Tool**: `magick identify icons/icon.ico` to verify multi-resolution contents.

---

## Phase 5: Bundle Configuration✅✅✅

- [ ] **Bundle targets** — restricted to Windows-only NSIS (already set in `tauri.conf.json`):
  ```json
  "bundle": {
    "targets": ["nsis"]
  }
  ```
  macOS/Linux builds would cross-compile from CI if needed; for local EXE builds, NSIS is the right target.

- [ ] **NSIS installer configuration** — already set in `tauri.conf.json`:
  - `installMode: "currentUser"` — no admin rights needed to install
  - Installer filename: `Code_Editor_<version>_x64-setup.exe`
  - For distribution, add license file at `src-tauri/bundle/licenses/License.txt`
  - For custom branding, add `installerIcon` and `sidebarImage` paths

- [ ] **MSI** — removed. MSI adds complexity (Wix toolchain) with no benefit here. NSIS covers all Windows install needs.

---

## Phase 6: Environment & Secrets

- [ ] No `.env` or `.env.local` files leaking into the build
- [ ] GitHub OAuth app client ID (if any) is configured for production, not localhost
- [ ] Any API keys are either:
  - Omitted (OAuth device flow needs none), or
  - Injected at build time via environment variables (not hardcoded)
- [ ] `src-tauri/tauri.conf.json` has no accidentally committed secrets

---

## Phase 7: Rust & Build Preparation

- [ ] Rust toolchain is up to date: `rustup update stable`
- [ ] `cargo build --release` succeeds (test independently first, ~5-15 min)
- [ ] Check for outdated Rust deps: `cargo outdated` (optional but recommended)
- [ ] Verify release profile in `Cargo.toml`:
  ```toml
  [profile.release]
  panic = "abort"
  codegen-units = 1
  lto = true
  opt-level = "s"     # or "z" for even smaller binary
  strip = true
  ```

---

## Phase 8: Code Signing (For Distribution)  [optional]

- [ ] Windows code signing certificate obtained (EV certificate recommended)
- [ ] Certificate thumbprint added to `tauri.conf.json`:
  ```json
  "bundle": {
    "windows": {
      "wix": {
        "sign": true,
        "certificateThumbprint": ""
      },
      "nsis": {
        "sign": true,
        "certificateThumbprint": ""
      }
    }
  }
  ```
- [ ] Test that signing works (`signtool verify /pa` on the signed EXE)

---

## Phase 9: Build & Validate 

- [ ] Run the final build: `npm run tauri build`
- [ ] **Build outputs**:
  - EXE at `src-tauri/target/release/code-editor.exe`
  - Installer at `src-tauri/target/release/bundle/nsis/Code_Editor_<version>_x64-setup.exe`
- [ ] **Verify installer** — install on a clean Windows VM/machine
- [ ] **Verify app** — run the installed app and test:
  - File tree navigation and file open/save
  - Multi-tab editing with Monaco
  - Terminal (PTY spawns)
  - Git operations (status, diff, commit, push)
  - GitHub panel (auth + API calls)
  - Theme switching
  - Search across files
  - Window resize, minimize, maximize, close
  - Keyboard shortcuts / command palette
- [ ] **Check console/logs** — no unhandled errors in the JS console (use Tauri DevTools on your build)
- [ ] **Memory baseline** — verify < 150 MB idle

## Notes

- **First Rust build is slow** (~5-15 min). Subsequent builds with minor changes are faster.
- **Concurrent builds**: Do NOT run `npm run tauri dev` while building — port conflict.
- **NSIS** is the installer format — no MSI needed (enterprise deployment not a target)
- Without code signing, Windows SmartScreen will block the installer — users must click "Run anyway"
